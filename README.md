# TwitchMessagesChecker (Telegram Bot)

Удобный многопользовательский Telegram-бот для мониторинга Twitch-каналов.
Вы можете подписаться на нужные каналы и задать ключевые слова (маски), и бот будет мгновенно уведомлять вас в Telegram, когда эти слова появятся в чате.

## Возможности
- **Интерактивный интерфейс:** Удобное меню с кнопками для добавления и управления подписками.
- **Изолированность:** Каждый пользователь получает уведомления только по своим подпискам, не мешая другим.
- **Оптимизация:** Даже если несколько человек подпишутся на один Twitch-канал, скрипт откроет только одно фоновое IRC-соединение для экономии ресурсов.
- **Авторизация:** Доступ к боту осуществляется по одноразовым 6-значным кодам (на 15 минут), чтобы ограничить доступ посторонним.

## Установка и запуск

1. Склонируйте репозиторий и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate
pip install pyTelegramBotAPI
```

2. Запустите генерацию кода авторизации для первого пользователя (вас):
```bash
python bot.py --generate-code
```
*Вы получите 6-значный код (например, 123456).*

3. Запустите бота (укажите ваш токен от BotFather):
```bash
python bot.py --token "YOUR_TELEGRAM_BOT_TOKEN"
```
*(Также токен можно передать через переменную окружения `TELEGRAM_BOT_TOKEN`)*

4. Перейдите в Telegram, нажмите `/start` и авторизуйтесь командой:
`/auth 123456`
